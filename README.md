# Gotham

Privacy is power. A proposed shielded pool for Elysium, and the site at [trygotham.tech](https://trygotham.tech).

Gotham is not deployed. The app at `/app` is a preview: it can read a public testnet balance after a wallet connects, and it cannot submit a shield, transfer, or withdrawal. The contracts under `contracts/` are an accounting sketch with no prover. Do not deploy them and do not send them funds.

The emblem in `public/brand/gotham-logo.png` is the official mark. Use that file. Do not redraw it.

The city plates in `public/gotham/` are original artwork for the hero. They are not a photograph of a place, and they are not the logo.

```bash
npm run dev
```

Network facts were checked against Elysium's documentation on 7 November 2026. Sources are linked from `/docs/elysium`. Mainnet addresses, RPCs, and explorers that the docs have not published are intentionally absent.
